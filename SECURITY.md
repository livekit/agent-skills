# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public issue.**

Instead, use [GitHub's private vulnerability reporting](https://github.com/livekit/agent-skills/security/advisories/new) to submit your report. This ensures the issue can be assessed and addressed before public disclosure.

For security issues in the broader LiveKit platform, please follow the reporting process at [https://livekit.io/security](https://livekit.io/security).

## Scope

This repository contains skill content (Markdown files) that guide AI coding agents. Security concerns here typically involve skill content that could cause agents to generate insecure code, such as:

- Guidance that leads to hardcoded credentials or secrets
- Patterns that introduce injection vulnerabilities
- Instructions that bypass authentication or authorization checks
- Advice that disables security features

## Response

We aim to acknowledge reports within 48 hours and provide a resolution timeline within 7 days.
